# FRBR upiti korišteni u usporedbi
Na temelju FRBR korisničkih zadataka, kreirano je osam upita koji su korišteni u usporedbi:
| Oznaka | Upit |
|---|---|
| U1 | Pronaći djelo prema naslovu |
| U2 | Pronaći sve autore određenog djela |
| U3 | Pronaći sve izraze određenog djela |
| U4 | Pronaći sve pojavne oblike određenog djela |
| U5 | Pronaći sve primjerke određenog djela |
| U6 | Pronaći hrvatske izraze djela i njihove prevoditelje |
| U7 | Pronaći pojavne oblike koji sadrže više izraza |
| U8 | Od konkretnog primjerka pronaći pripadajuće djelo |

SQL i Cypher verzije svakog upita koriste isti skup podataka i vraćaju funkcionalno usporedive rezultate.
